# ClimaPro - Plataforma Web Oficial (Hermosillo y Alrededores)

Sitio web moderno de alta conversión para **ClimaPro (Climatización & Refrigeración)**, especializado en la atención rápida a fallas frecuentes de aire acondicionado en Hermosillo, Sonora.

---

## 🚀 Tecnologías Utilizadas

- **React 18**: Arquitectura moderna basada en componentes.
- **Vite 6**: Compilador ultrarrápido y optimizado para producción.
- **Tailwind CSS 3**: Sistema de diseño responsivo basado en la paleta oficial del logotipo.
- **Framer Motion**: Animaciones fluidas, microinteracciones y efectos de entrada.
- **Lucide React**: Iconografía técnica y profesional.

---

## 📋 Características Principales

1. **Selector Inteligente de Síntomas**:
   - 💨 **No arroja mucho aire**: Diagnóstico de turbina y filtros sucios.
   - 🔥 **No enfría / Tira aire tibio**: Fuga de gas refrigerante, capacitor o compresor.
   - 🤢 **Huele a humedad o vinagre**: Sanitización de moho y colonias bacterianas.
   - 💧 **Chorrea o gotea agua**: Desazolve de drenaje a presión y nivelación.

2. **Tarifa Base Transparente**:
   - Destacado visual de **$400 MXN** como tarifa base para cualquier tipo de sistema (Mini-Split, Central, Piso-Techo, etc.) y cantidad de equipos.

3. **Motor de Agendamiento Directo a WhatsApp**:
   - Conexión configurada con el número oficial: `+52 662 420 5643`.
   - Generación de mensajes estructurados con todos los datos del cliente, falla, equipo, fecha y ubicación en Hermosillo.

4. **SEO Local y OpenGraph**:
   - Marcado semántico `Schema.org/HVACBusiness` para posicionamiento en Google Hermosillo.
   - Vista previa enriquecida al compartir el enlace por WhatsApp y redes sociales.

## 🛠️ Comandos de Desarrollo

### Instalar dependencias
```bash
npm install
```

### Iniciar servidor de desarrollo local
```bash
npm run dev
```

### Compilar para producción
```bash
npm run build
```

### Previsualizar la compilación de producción
```bash
npm run preview
```

## ☁️ Cómo Desplegar Gratis en Vercel

### Opción A: Desde la Web de Vercel (Recomendado)
1. Sube este proyecto a tu repositorio de GitHub.
2. Ingresa a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
3. Haz clic en **"Add New Project"** e importa el repositorio de **CLIMAPRO**.
4. Vercel detectará automáticamente que es un proyecto **Vite**.
5. Haz clic en **"Deploy"**. En menos de 1 minuto tendrás tu enlace público `https://climapro-....vercel.app` con SSL/HTTPS gratis.

### Opción B: Mediante Vercel CLI en Terminal
```bash
npm i -g vercel
vercel
```
Sigue las instrucciones en pantalla y tu sitio estará en línea al instante.
